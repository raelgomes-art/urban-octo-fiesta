Este é o site oficial do clã **TXFA**, desenvolvido com foco em Apex Legends. O projeto foi estruturado para apresentar o time, listar as diretrizes internas, apresentar os integrantes ativos e servir como uma plataforma direta para recrutamento de novos membros.

## 🎨 Identidade Visual e Design

- **Paleta de Cores:** Baseada no conceito moderno "vermelho carmesim e preto", trazendo a atmosfera competitiva do jogo.
- **Efeito Visual:** Integração de uma marca d'água suave com o brasão do clã estilizado ao fundo da página.
- **Interface Responsiva:** Desenvolvida para se adaptar perfeitamente tanto a telas de computadores quanto a dispositivos móveis.

## 🚀 Funcionalidades

- **Apresentação & Diretrizes:** Seção dedicada às regras, valores e objetivos competitivos e casuais do clã.
- **Lista de Integrantes:** Área dinâmica para apresentar os membros atuais da equipe.
- **Central de Contato e Recrutamento:** Links integrados direcionando diretamente para o WhatsApp e Gmail oficiais, facilitando a entrada de novos candidatos.

## 🛠️ Tecnologias Utilizadas

- **Estruturação:** HTML5
- **Estilização e Responsividade:** CSS3 / Tailwind CSS
- **Hospedagem:** Netlify (Deploy automatizado)

## 📦 Como Visualizar o Projeto Localmente

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` diretamente em seu navegador ou utilize a extensão *Live Server* no VS Code para rodar o ambiente de desenvolvimento local.
